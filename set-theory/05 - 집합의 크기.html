무한집합과 유한집합

정의 — 무한집합 · 유한집합 (Dedekind)

집합 $X$의 진부분집합 $Y$가 존재하고 $X \sim Y$ (일대일 대응)이면 $X$를 무한집합이라 한다.
무한집합이 아닌 집합을 유한집합이라 한다.

정리 — 무한·유한집합의 성질

(1) $X$가 무한이고 $X \subset Z$이면 $Z$도 무한집합

(2) $X$가 유한이고 $Z \subset X$이면 $Z$도 유한집합

(3) $f: X \to Y$가 전단사이면, $X$가 무한 $\iff$ $Y$가 무한

정리 — 유한집합의 특성

공집합이 아닌 집합 $X$가 유한집합 $\iff$ 적당한 $k \in \mathbb{N}$에 대해
$X \sim \mathbb{N}_k = \{1, 2, \ldots, k\}$

집합의 대등

정의 — 대등 (Equipotent)

$X$와 $Y$ 사이에 전단사함수가 존재할 때, $X$와 $Y$가 대등(equipotent)하다고 하고
$$X \sim Y$$
로 나타낸다.

보조정리 — 대등은 동치관계

집합들의 집합 $\mathcal{F}$ 위에서 $R = \{(X,Y) \mid X \sim Y\}$는 동치관계이다.
(반사: 항등함수, 대칭: 역함수, 추이: 합성함수)

정리 — 대등과 합집합

$X \cap Z = \varnothing$, $Y \cap W = \varnothing$이고 $f: X \sim Y$, $g: Z \sim W$이면
$$f \cup g: X \cup Z \sim Y \cup W$$

정리 — 대등과 Cartesian 곱

$f: X \sim Y$, $g: Z \sim W$이면 $f \times g: X \times Z \sim Y \times W$

정리 — 대등과 함수 집합

$f: X \sim Y$, $g: Z \sim W$이면 $X^Z \sim Y^W$

(전단사 $\Phi: X^Z \to Y^W$는 $\Phi(h) = f \circ h \circ g^{-1}$으로 구성)

보조정리 — 멱집합과 $2^X$의 대등

임의의 집합 $X \neq \varnothing$에 대해
$$\mathcal{P}(X) \sim 2^X = \{0,1\}^X$$
(특성함수 $\chi_A(x) = 1\text{ if }x \in A$, $0\text{ if }x \notin A$로 전단사 구성)

가부번집합

정의 — 가부번집합 (Countable Set)

$X \sim \mathbb{N}$인 집합을 가부번집합(countable/denumerable set)이라 한다.

정리 — 가부번집합의 합집합

가부번집합 $X = \{x_1, x_2, \ldots\}$, $Y = \{y_1, y_2, \ldots\}$가 서로소이면 $X \cup Y$도 가부번집합이다.

(전단사: $f(n) = x_{(n+1)/2}$ (홀수), $f(n) = y_{n/2}$ (짝수))

정리 — $\mathbb{N} \times \mathbb{N}$은 가부번집합

Cantor 짝짓기 함수:
$$f(m, n) = \frac{(m+n-2)(m+n-1)}{2} + m$$
이 전단사함수를 이룬다. ($m+n$ 대각선 방향으로 번호를 매기는 방식)

정리 — $\mathbb{Q}$는 가부번집합
  • $\mathbb{Q}^+$: $\mathbb{N} \times \mathbb{N} \to \mathbb{Q}^+$, $(m,n) \mapsto m/n$이 전사이므로 가부번
  • $\mathbb{Q}^- \sim \mathbb{Q}^+$ (부호 반전)
  • $\mathbb{Q} = \mathbb{Q}^+ \cup \mathbb{Q}^- \cup \{0\}$ — 가부번집합의 유한 합집합
정리 — 가부번집합의 가산합

(1) 서로소인 가부번집합들의 가산 합집합 $\bigcup_{k=1}^\infty A_k$도 가부번집합

(2) 임의의 무한집합 $X$에 대하여 $X$의 가부번 부분집합 $Y$가 존재한다

비가부번 무한집합

정리 — Cantor의 대각법

실수 집합 $\mathbb{R}$의 열린구간 $(0, 1)$은 비가부번 무한집합이다.

증명 — 증명 (Cantor 대각법)

$(0,1)$이 가부번집합이라 가정하면, 모든 원소를 $x_1, x_2, x_3, \ldots$으로 나열할 수 있다.

각 $x_n$을 십진 소수로 표현:
$$x_n = 0.a_{n1}a_{n2}a_{n3}\cdots$$

새로운 수 $y = 0.b_1b_2b_3\cdots$를 대각 성분과 다르게:
$$b_n = \begin{cases} 1 & a_{nn} \neq 1 \\ 2 & a_{nn} = 1 \end{cases}$$

그러면 $y \in (0,1)$이지만 모든 $n$에 대해 $y \neq x_n$ ($n$번째 자리가 다름).
이는 모든 원소를 나열했다는 가정에 모순. $\square$

정리 — 따름정리

(1) $\mathbb{R}$은 비가부번 무한집합

(2) 무리수 집합 $\mathbb{R} \setminus \mathbb{Q}$는 비가부번 무한집합

(3) 단위원 $S^1 = \{(x,y) \mid x^2 + y^2 = 1\}$은 비가부번 무한집합
(전단사: $f: [0,1) \to S^1$, $f(t) = (\cos 2\pi t, \sin 2\pi t)$)

(4) 비가부번 $X$와 가부번 $Y$에 대해 $X - Y \sim X$ (가부번을 제거해도 크기 보존)

(5) $\mathbb{R} \setminus \mathbb{Q} \sim \mathbb{R}$

기수와 기수의 대소

공리 — 기수 공리 (C1~C4)
  • C1: 임의의 집합 $A$에 대해 기수 $\operatorname{card}(A)$가 유일하게 존재한다
  • C2: $A \sim \varnothing \iff \operatorname{card}(A) = 0$
  • C3: $A \sim \mathbb{N}_k$이면 $\operatorname{card}(A) = k$
  • C4: $A \sim B \iff \operatorname{card}(A) = \operatorname{card}(B)$
정의 — 기수의 대소
  • $\operatorname{card}(A) \leq \operatorname{card}(B)$: $A$가 $B$의 어떤 부분집합과 대등
  • $\operatorname{card}(A) < \operatorname{card}(B)$: $\leq$이지만 $A \not\sim B$

주요 기수:
$$\operatorname{card}(\mathbb{N}) = \aleph_0, \qquad \operatorname{card}(\mathbb{R}) = c = 2^{\aleph_0}$$
$$\aleph_0 < c$$

Cantor–Schröder–Bernstein 정리

정리 — Cantor–Schröder–Bernstein (CSB)

단사함수 $f: A \to B$와 단사함수 $g: B \to A$가 존재하면
$$A \sim B$$

정리 — CSB의 따름정리

(1) 임의의 두 집합 $A, B$에 대해 $\operatorname{card}(A) < \operatorname{card}(B)$, $=$, $>$ 중 정확히 하나만 성립

(2) $A \subset B \subset C$이고 $A \sim C$이면 $A \sim B \sim C$

(3) 임의의 무한집합 $A$와 $a \in A$에 대해 $A \sim A - \{a\}$

Cantor 정리와 연속체 가설

정리 — Cantor 정리

임의의 집합 $X$에 대해
$$\operatorname{card}(X) < \operatorname{card}(\mathcal{P}(X))$$

정리 — 따름정리

$X$가 가부번집합이면 $\mathcal{P}(X)$는 비가부번 무한집합.

$X \sim Y$이면 $\operatorname{card}(\mathcal{P}(X)) = \operatorname{card}(\mathcal{P}(Y))$.

가설 — 연속체 가설 (Continuum Hypothesis, CH)

$\aleph_0 < a < 2^{\aleph_0} = c$를 만족하는 초한기수 $a$는 존재하지 않는다.

가설 — 일반 연속체 가설 (GCH)

임의의 초한기수 $a$에 대해 $a < b < 2^a$를 만족하는 초한기수 $b$는 존재하지 않는다.

비고 — 독립성

Gödel(1938)과 Cohen(1963)은 CH가 ZFC 공리계로부터 독립적임을 증명했다.
즉, CH는 ZFC에서 증명도 반증도 불가능하다.

기수의 연산

기수에는 덧셈, 곱셈, 거듭제곱이 정의된다. 뺄셈과 나눗셈은 정의하지 않는다.

정의 — 기수 연산

$\operatorname{card}(A) = x$, $\operatorname{card}(B) = y$일 때:

  • 합: $x + y = \operatorname{card}(A \cup B)$ ($A \cap B = \varnothing$)
  • 곱: $xy = \operatorname{card}(A \times B)$
  • 거듭제곱: $x^y = \operatorname{card}(A^B)$ ($A^B$: $B$에서 $A$로의 모든 함수의 집합)
정리 — 기수 연산의 주요 결과

$$2^{\aleph_0} = c, \qquad \aleph_0 < c = 2^{\aleph_0}$$
$$c^{\aleph_0} = c^k = c \quad (k \geq 2 \text{ 유한})$$
$$k^{\aleph_0} = \aleph_0^{\aleph_0} = c$$
$$a \leq b, x \leq y \Rightarrow a^x \leq b^y$$
