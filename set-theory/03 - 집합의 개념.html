집합과 부분집합

집합을 정의하기 위해 무정의 용어(원소, 모임)를 허용한다.
집합을 우리의 직관과 사고를 통해 뚜렷이 구별할 수 있는 대상들의 모임 으로 약간 모호하게 정의한다.

  • 원소가 없는 집합: 공집합 $\varnothing$
  • 원소가 하나인 집합: 단집합(singleton)
  • 원소나열법: 순서 무관, 중복 시 한 번만 표기 (중복 허용 시: 다중집합 multi-set)
  • 조건제시법: 명제함수 이용
정의 — 부분집합

두 집합 $A$와 $B$에 대하여 $A$의 모든 원소가 $B$의 원소일 때,
$A$는 $B$의 부분집합(subset)이라 하고 $A \subset B$ 또는 $A \subseteq B$로 나타낸다:
$$x \in A \Rightarrow x \in B$$
$A \subset B$이지만 $A \neq B$일 때, $A$를 $B$의 진부분집합(proper subset)이라 한다.

[!definition] 집합의 동등
$$A = B \iff A \subset B \wedge B \subset A \iff (x \in A \Leftrightarrow x \in B)$$

[!theorem] 부분집합의 기본 성질
(1) 공집합 $\varnothing$은 모든 집합의 부분집합이다.

(2) 임의의 집합 $A$가 $\varnothing$의 부분집합이면 $A = \varnothing$이다.

(3) $A \subset B$이고 $B \subset C$이면 $A \subset C$ — 추이성

[!definition] 멱집합 (Power Set)
임의의 집합 $A$에 대하여:
$$\mathcal{P}(A) = {C \mid C \subset A}$$

합집합과 교집합

정의 — 합집합과 교집합

(합집합, union)
$$x \in A \cup B \Leftrightarrow x \in A \vee x \in B$$

(교집합, intersection)
$$x \in A \cap B \Leftrightarrow x \in A \wedge x \in B$$

특히 $A \cap B = \varnothing$일 때, $A$와 $B$가 서로소(mutually disjoint)라 한다.

[!theorem] 집합 연산의 기본 법칙
집합 $X$의 부분집합 $A, B, C$에 대하여:

(1) $A \cup \varnothing = A,\quad A \cap X = A$ — 항등법칙

(2) $A \cup A = A,\quad A \cap A = A$ — 멱등법칙

(3) $A \cup B = B \cup A,\quad A \cap B = B \cap A$ — 교환법칙

(4) $A \cup (B \cup C) = (A \cup B) \cup C$ — 결합법칙

(5) $A \cap (B \cup C) = (A \cap B) \cup (A \cap C)$ — 분배법칙

[!lemma] 부분집합과 연산의 관계
(1) $A \subset B \iff A \cup B = B$

(2) $A \subset B \iff A \cap B = A$

(3) $A \cup B = A \cap B \iff A = B$

[!lemma] 멱집합의 성질
(1) $A \subset B \iff \mathcal{P}(A) \subset \mathcal{P}(B)$

(2) $\mathcal{P}(A) \cap \mathcal{P}(B) = \mathcal{P}(A \cap B)$

(3) $\mathcal{P}(A) \cup \mathcal{P}(B) \subset \mathcal{P}(A \cup B)$

차집합과 여집합

정의 — 차집합과 여집합

(1) 차집합(relative complement):
$$A - B = {x \in A \mid x \notin B}$$

(2) 전체집합 $U$의 부분집합 $A$에 대한 여집합(complement):
$$A^{c} = U - A$$

[!theorem] 여집합의 성질
전체집합 $U$와 $U$의 부분집합 $A, B$에 대하여:

(1) $A - B = A \cap B^{c}$
(2) $(A^{c})^{c} = A$
(3) $\varnothing^{c} = U,\quad U^{c} = \varnothing$
(4) $A \cap A^{c} = \varnothing,\quad A \cup A^{c} = U$
(5) $A \subset B \Leftrightarrow B^{c} \subset A^{c}$

[!theorem] De Morgan의 법칙 (집합)
$$(A \cap B)^{c} = A^{c} \cup B^{c}, \qquad (A \cup B)^{c} = A^{c} \cap B^{c}$$

첨수집합족

정의 — 첨수집합족 (Indexed Family of Sets)

집합 $\Gamma$와 각각의 $\gamma \in \Gamma$에 대해 $A_{\gamma}$가 대응할 때,
$\gamma$를 첨수(index), $\Gamma$를 첨수집합이라 한다:
$$\mathcal{F} = {A_{\gamma} \mid \gamma \in \Gamma}$$

[!definition] 일반 합집합과 교집합
(1) $\displaystyle\bigcup_{\gamma \in \Gamma} A_{\gamma} = {x \in U \mid x \in A_{\gamma}\text{를 만족하는 } A_{\gamma}\text{가 존재}}$

(2) $\displaystyle\bigcap_{\gamma \in \Gamma} A_{\gamma} = {x \in U \mid \text{모든 } \gamma \in \Gamma,\; x \in A_{\gamma}}$

[!theorem] 일반 De Morgan의 법칙
$$\left(\bigcup_{\gamma \in \Gamma} A_{\gamma}\right)^{c} = \bigcap_{\gamma \in \Gamma} A_{\gamma}^{c}, \qquad \left(\bigcap_{\gamma \in \Gamma} A_{\gamma}\right)^{c} = \bigcup_{\gamma \in \Gamma} A_{\gamma}^{c}$$

[!theorem] 분배법칙 (일반)
$$B \cap \left(\bigcup_{\gamma \in \Gamma} A_{\gamma}\right) = \bigcup_{\gamma \in \Gamma} (B \cap A_{\gamma}), \qquad B \cup \left(\bigcap_{\gamma \in \Gamma} A_{\gamma}\right) = \bigcap_{\gamma \in \Gamma} (B \cup A_{\gamma})$$

Russell의 역설

동기와 배경

19세기 말 나이브 집합론은 "임의의 성질 $P(x)$를 만족하는 모든 대상의 모임 ${x \mid P(x)}$은 집합이다"라는 비제한적 이해 원리에 의존하였다.
이 원리는 곧바로 Russell의 역설을 낳는다.

정의 — 비제한적 이해 원리

임의의 공식 $P(x)$에 대해 ${x \mid P(x)}$가 항상 집합으로 존재한다고 가정하는 원리.

[!definition] Russell의 집합(류)
$$\mathcal{R} = {x \mid x \notin x}$$
나이브 집합론에서는 이것을 집합으로 간주할 수 있으나, ZFC에서는 집합이 아닌 대상(진류; proper class)으로 취급된다.

[!theorem] Russell의 역설
나이브 집합론에서 $\mathcal{R} = {x \mid x \notin x}$를 집합으로 인정하면 모순이 발생한다.

[!proof]- 증명
$\mathcal{R} \in \mathcal{R}$라고 가정하면 정의상 $\mathcal{R} \notin \mathcal{R}$.
반대로 $\mathcal{R} \notin \mathcal{R}$이면 정의상 $\mathcal{R} \in \mathcal{R}$.
따라서 $\mathcal{R} \in \mathcal{R} \iff \mathcal{R} \notin \mathcal{R}$ — 모순. $\square$

ZFC의 해결책

정의 — 분리 공리 (Axiom Schema of Separation)

주어진 모체 집합 $A$와 공식 $\varphi(x)$에 대하여
$$B = {x \in A \mid \varphi(x)}$$
가 집합으로 존재한다는 공리족. 전 우주에서의 필터링은 허용하지 않는다.

[!definition] 진류 (Proper Class)
공식으로 서술 가능하더라도 ZFC에서 집합으로 형성되지 않는 대상.
진류는 어떤 집합의 원소가 될 수 없다 (예: "모든 집합들의 모임").

[!theorem] 보편집합은 존재하지 않는다
모든 집합을 원소로 갖는 집합 $U$는 ZFC에서 존재하지 않는다.

[!proof]- 증명
$U$가 존재한다고 하자. 멱집합 공리에 의해 $\mathcal{P}(U)$가 존재하고,
모든 부분집합은 $U$의 원소이므로 $\mathcal{P}(U) \subseteq U$, 즉 $|\mathcal{P}(U)| \leq |U|$.
그러나 Cantor 정리에 의해 항상 $|\mathcal{P}(U)| > |U|$. 모순. $\square$

[!theorem] Cantor 정리
임의의 집합 $A$에 대해 $|\mathcal{P}(A)| > |A|$.

[!proof]- 증명
$f : A \to \mathcal{P}(A)$가 전사라 가정하고
대각선 집합 $D = {x \in A \mid x \notin f(x)}$를 잡으면,
임의 $a \in A$에 대해 $f(a) = D$이면 $a \in D \iff a \notin f(a) = D$ — 모순.
따라서 전사는 존재하지 않는다. $\square$

요약

요약 — Russell의 역설 요약
  • 문제: 비제한적 이해 원리 → $\mathcal{R} = {x \mid x \notin x}$ → 모순
  • 해결: ZFC의 분리 공리로 집합 형성을 모체 내부로 제한
  • 결과: Russell류는 진류(proper class)로만 기술되며, 공리적 틀에서 모순 차단
  • 보편집합: Cantor 정리에 의해 ZFC에서 존재 불가

자가점검 (T/F)

명제 답 이유
무정의 용어가 있으면 역설이 발생한다 F 문제는 정의로부터의 존재 남발
분리 공리는 전 우주에서의 필터링을 허용한다 F 반드시 모체 집합 내부
ZFC에서 모든 집합들의 집합이 존재하지 않는다 T Cantor 정리로 증명
$\mathcal{R}$은 ZFC에서 집합이다 F 진류로만 기술 가능
